# IMDb Dataset Cleaning — Google Sheets

## 📌 Project Overview

This project focuses on cleaning and preparing a messy IMDb dataset using Google Sheets. The goal is to improve data quality by identifying and handling inconsistencies in the raw dataset, making it more structured and suitable for further analysis.

Data cleaning is an essential step in the data analysis process because inaccurate, inconsistent, or improperly formatted data can affect the reliability of analytical results.

## 🎯 Project Objectives

- Identify data quality issues in the raw IMDb dataset.
- Standardize inconsistent text and date formats.
- Handle unnecessary spaces and formatting inconsistencies.
- Improve data consistency and readability.
- Prepare a clean dataset for further exploratory data analysis (EDA).

## 🛠️ Tools & Technologies

- **Google Sheets** — Data cleaning and data preparation.
- **Spreadsheet Formulas** — Text manipulation, date formatting, and data standardization.

## 🔍 Data Cleaning Process

The project follows these data cleaning steps:

1. **Data Inspection**
   Examined the raw dataset to identify inconsistent values and formatting issues.

2. **Text Cleaning**
   Identified and removed unnecessary spaces and standardized text values where necessary.

3. **Date Standardization**
   Standardized date formats to ensure consistency across records.

4. **Data Type Validation**
   Checked and corrected data types, including dates and numeric values, to ensure they could be interpreted correctly.

5. **Data Validation**
   Reviewed the cleaned data to ensure formatting consistency and improve data usability.
